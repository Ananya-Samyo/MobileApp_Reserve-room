## 📖 เกี่ยวกับโปรเจค

**MobileApp_Reserve-room** เป็นแอปพลิเคชันมือถือที่ช่วยให้ผู้ใช้งานสามารถ **จองห้องประชุม / ห้องใช้งานต่าง ๆ จากอุปกรณ์มือถือได้อย่างสะดวก**  
แอปนี้ออกแบบโดยใช้เทคโนโลยี **cross-platform mobile development** เพื่อให้รองรับการทำงานทั้งบน Android และ iOS 

แอปมีเป้าหมายเพื่อให้ผู้ใช้สามารถ:

- ดูรายการห้องได้พร้อมรายละเอียด  
- เลือกช่วงเวลาและวันที่สำหรับการจอง  
- ส่งคำขอจองจากมือถือ  
- จัดการสถานะการจองย้อนหลัง

## ✨ ฟีเจอร์หลัก

📍 **ดูรายการห้อง**  
แสดงรายการห้องที่พร้อมให้จอง

🗓 **เลือกเวลาการจอง**  
ผู้ใช้สามารถเลือกวันที่และช่วงเวลาได้

📩 **ระบบส่งคำขอจอง**  
ส่งคำขอจองไปยังระบบ backend

📊 **สถานะการจอง**  
แสดงสถานะการจองที่ผู้ใช้สร้างแล้ว

📱 **UI ที่เหมาะกับมือถือ**  
ออกแบบหน้าแอปให้เป็น mobile-friendly
